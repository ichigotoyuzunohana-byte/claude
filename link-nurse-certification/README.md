# 感染管理リンクナース認定制度

各部署の感染対策を現場で推進する「リンクナース」を、院内研修を通じて選出・育成・認定するための制度一式（ドラフト）。

## ファイル

- `感染管理リンクナース認定制度規程.docx` — 規程本文（総則／選出・任期／資格認定／育成研修／役割・活動／認定の更新・取消）と、別紙（育成研修カリキュラム例、認定申請書・活動報告書の様式）
- `制度概要.html` — 制度の位置づけ・認定フロー・育成カリキュラム・役割をまとめた1枚もの概要（[公開版](https://claude.ai/code/artifact/262aeadb-1f55-4b20-a5d6-3232f0be8408)）

## 前提・注意事項

- 病院名・施行日・所管部署などは `[ ]` のプレースホルダになっており、各院の実情に合わせて確定させる必要がある。
- 育成研修の時間数・回数は法令等で一律に定められたものではなく、他院の一般的な実践例を踏まえた設計例。感染管理認定看護師（ICN）のような国家規模の統一カリキュラムはリンクナースには存在しない。
- 医療法施行規則に基づく全職員対象の院内感染対策研修（年2回以上）とは別に、これを補完する専門研修としての位置づけ。
- 実際の患者情報・院内固有情報は一切含まれていない（ダミーの施設名・様式のみ）。
