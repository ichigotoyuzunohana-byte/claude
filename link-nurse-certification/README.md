# 感染管理リンクナース認定制度

ICT活動の一環として既に存在する「リンクナース会」について、役割・求められる能力を明確化し、月次ミニレクチャー（既存・15分）＋eラーニング＋オンラインフォームの確認テストによる教育と、修了・認定の仕組みを整えるドラフト一式。

## ファイル

- `感染管理リンクナース認定制度規程.docx` — 規程本文（総則／役割・求められる能力／教育体系／認定／雑則）と、別紙（コンピテンシー一覧、年間教育計画例、修了・認定基準例）
- `制度概要.html` — 位置づけ・役割とコンピテンシー・月次教育サイクル・年間教育計画をまとめた1枚もの概要（[公開版](https://claude.ai/code/artifact/262aeadb-1f55-4b20-a5d6-3232f0be8408)）

## 制度の骨子

1. **役割の明確化** — 「部署の感染の仕事をする人」から、7つの具体的な役割（日常観察・情報伝達・フィードバック・サーベイランス協力・緊急時対応・教育など）へ
2. **求められる能力（コンピテンシー）** — 知識／技術／実践・連携の3領域×到達目安で整理
3. **教育サイクル（毎月）** — ①月次ミニレクチャー（既存・15分）→ ②eラーニングで補完 → ③オンラインフォームで確認テスト → ④テーマ単位の「修了」を記録
4. **年度認定** — 年間の修了記録の累積（出席率・テスト結果）が基準を満たした者を年度末に「認定リンクナース」として認定・更新

## 前提・注意事項

- 病院名・施行日・所管部署などは `[ ]` のプレースホルダになっており、各院の実情に合わせて確定させる必要がある。
- コンピテンシー一覧・年間教育計画・修了/認定の基準値（出席率80%、正答率70%など）はいずれも設計例。法令等で一律に定められた統一基準ではなく、運用しながら院内で見直すことを前提とする。
- 確認テストの実施ツール（Googleフォーム等）は例示であり、本ドラフトは具体的な設問は含まない。
- 実際の患者情報・院内固有情報は一切含まれていない（ダミーの施設名・様式のみ）。
