## 1. 背景と課題

- 利用者の勤務先では、**ICT（感染制御チーム）活動の一環として「リンクナース会」が既に存在している**。
  これは新設ではなく、既に運用されている組織である。
- しかし現状、リンクナースの位置づけが **「部署の感染の仕事をする人」という曖昧なもの** に
  とどまっており、役割と求められる能力が明文化されていない。
- 一方で、**月1回・15分程度のミニレクチャーを既に実施している**という運用上の資産がある。

### 利用者が実現したいこと

1. リンクナースの**役割**を明確にする
2. リンクナースに**求められる能力**を明確にする
3. 既存の月次ミニレクチャーを活かしつつ、**eラーニング**で教育を補完する
4. 最終的に**フォーム（Googleフォーム等）でテスト**を行い、**「認定」または「修了」**とする

## 2. これまでの決定事項

| 論点 | 決定内容 | 決定の理由 |
|---|---|---|
| 制度のタイプ | リンクナース型（各部署1〜2名の窓口役を院内基準で認定） | 上位資格型（ICN・ICMT保有者向け）ではなく、既存のリンクナース会の実態に合うため |
| 「認定」か「修了」か | **2段階構成**。テーマ単位＝「修了」、年間累積＝「認定」 | 毎月テーマが変わる運用と、年次で称号を与える運用の両方を無理なく満たせるため |
| 認定の有効期間 | **年度ごとの更新制**（有効期間は交付年度末まで） | 会が毎月動いているなら、2年任期の重い認定より学習実績が毎年リセットされる形がサイクルと噛み合うため |
| 教育の中核 | 既存の月次ミニレクチャー（15分）を核とし、eラーニングで補完 | 新しい研修を増やすのではなく既存資産を活用する方針 |
| 欠席時の扱い | eラーニング視聴をもって代替出席とみなす | 15分の会に出られない人が出ても実施率が崩れないようにするため。新任者が過去テーマを遡って学べる効果もある |
| 成果物の形式 | Word（規程・要綱）＋ HTML（制度概要・図解） | 利用者の選択による |

### 判定基準（設計例・要確定）

| 項目 | 基準（例） |
|---|---|
| 各回の「修了」 | ミニレクチャー出席 または eラーニング視聴　＋　確認テスト正答率 **70%以上** |
| 年間「認定」（出席・視聴） | 年間12回のうち **80%以上（10回以上）** の修了 |
| 年間「認定」（テスト） | 各回テストの平均正答率 **70%以上**　かつ　年度末の総合確認テスト **70%以上** |
| 未達の場合 | 感染対策委員会が個別に補講・再テストの機会を設けることができる |

> **重要**：上記の数値（80%・70%）は**法令等に根拠のある統一基準ではなく、
> 運用しながら院内で調整する前提で置いた設計例**です。この点はユーザーにも
> 明示済みですが、成果物を扱う際は誤って「標準基準」として記述しないでください。

## 6. 次にやるべきこと（タスク候補）

優先度順。ユーザーが「次はこれ」と指定した場合はそれを優先してください。

1. **確認テストの設問作成** — 12テーマ × 各5問程度。前セッションの最後に
   ユーザーへ提案し、まだ着手していない。教材（ミニレクチャー内容）と
   コンピテンシー一覧の対応を保つこと
2. **受講記録の管理表（Excel）** — 出席／eラーニング視聴／テスト結果を12か月分記録し、
   年度末の認定判定を自動計算する形にすると運用が楽になる
3. **リンクナース会での制度説明資料** — 制度導入をメンバーに説明するスライド。
   既存の `制度概要.html` を土台にできる
4. **感染対策委員会への上程資料** — 規程案の承認を得るための提案文書
5. **認定証の様式** — Word/PDFテンプレート
6. 規程内プレースホルダの確定（5-1 の回答を受けて反映）

## 8. 制度の骨子（1枚要約）

```
【現状】ICT内にリンクナース会あり。ただし役割が曖昧。月1回15分のミニレクチャーを実施中。
                              ↓
【役割の明確化】7つの具体的役割（日常観察／情報伝達／ICTへのフィードバック／
                サーベイランス協力／アウトブレイク初期対応／新人教育／PPE助言）
                              ↓
【能力の明確化】コンピテンシー一覧＝知識・技術・実践/連携 の3領域 × 到達の目安
                              ↓
【毎月のサイクル】① ミニレクチャー15分（既存）
                  → ② eラーニングで補完（欠席者・新任者もここで追いつける）
                  → ③ 確認テスト（オンラインフォーム）
                  → ④ テーマ単位の「修了」を記録
                              ↓
【年度末】12か月分の修了記録を集計 → 基準を満たせば「認定リンクナース」として認定
          → 翌年度も同じ基準で更新（年度更新制）
```
